## 🤖 Generative AI Projects

### 3. Mini Rule-Based Chatbot
- Interacts with users through the terminal.
- Provides predefined responses to common questions.
- Supports continuous conversations.
- Exits when the user types `bye`.
- **Concepts:** Python input/output, conditions, loops, string methods.

### 4. AI Content Generator
- Generates content using a locally running LLM.
- Accepts a topic from the user.
- Supports different content types:
  - Instagram captions
  - Blog posts
  - Professional emails
  - Study notes
- Supports different writing tones:
  - Friendly
  - Professional
  - Motivational
- Uses Ollama to communicate with the Llama language model.
- **Concepts:** Generative AI, LLM integration, prompt engineering, Python API requests.

**Technologies:** Python, Ollama, Llama 3.2 1B, Requests.

**Project location:** `Generative-AI-Projects/AI-Content-Generator/`
